# EG-S1 git 探针运行记录

环境：macOS，git 2.50.1 (Apple Git-155)，2026-10-14。探针：`EG-S1-git-probes.sh`。

| 次序 | 探针版本 | 结果 |
|---|---|---|
| 1 | 初版 | F-12、F-13、F-14b 失败：初版假设未跟踪文件可直接用 `git commit -- <path>` 提交，实测不行（即 F-16）。属探针假设错误，已改为先 `add` 再 `commit --only` |
| 2 | 修正版 | F-14b 失败（钩子中止后 `--no-verify` 提交仍失败），其余通过 |
| 3 | 修正版，不屏蔽 stderr 的调试副本 | 全部通过 |
| 4—8 | 修正版 | 连续 5 次全部通过 |

| 9 | B1 审查后（F-15 改为 v2） | 见下文"F-15 更正" |

结论：

- F-11、F-12、F-12b、F-13、F-14、F-15、F-16 稳定通过。
- F-14b（`--no-verify` 跳过钩子）6 次正式运行中 1 次失败，原因未查明，记为不稳定；EG-S1 不应依赖它。
- 第 1 次运行的失败说明：按"直接 `commit -- <path>`"写出的提交步骤会在第一次提交新文件时失败。

## F-15 更正（EG-S1 B1 审查 B1-05）

旧版 F-15 用未跟踪的新文件测试"未配置身份时提交失败"，失败的真实原因是 F-16（未跟踪文件须先 add），与身份无关；探针因错误的原因通过。实测：git 2.50.1 在 macOS 上未配置身份时，对已跟踪文件的提交会以自动推断的身份（系统用户名与主机名）成功。

新版 F-15 改用已跟踪文件，并加对照 F-15c（配置身份后同一操作必须成功）。教训记为复盘候选 RC-09：探针与测试一样需要对照，证明它是因为所声称的原因通过或失败。
