# engineering-gates v2 流程设计：讨论记录

> 状态：讨论中。创建：2026-10-14。
> 已确认决定的唯一权威是同目录的 `decisions.json`；本文件只记录问题、选项、用户回答和来源，不以历史内容覆盖登记中的当前状态。

## 1. 目标

形成一套在不同 harness、不同 LLM 上都能稳定执行的开发流程：问答式讨论形成决策与设计稿，设计稿切分为一个或多个 spec，spec 经审查确认与设计对齐，按 spec 实现，实现再经审查确认正确。

## 2. 对话规则

1. 每轮只讨论一个问题；选项互斥，说明实现方式、收益、代价和对后续设计的影响，给出建议，由用户决定。
2. 讨论新问题前，先检查它是否已被已有决定全部或部分关闭，必要时先校正题面。
3. 只有用户明确接受的结论才登记为决定；解释过程中的临时说法不写成决定。
4. 推翻旧决定时不删除历史，在登记中标记替代关系并说明原因。
